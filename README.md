# 药物浓度响应的细胞状态轨迹：可解释模型与内部基准评测

**GitHub 仓库：[github.com/666Beginner999/cell-state-dose-response](https://github.com/666Beginner999/cell-state-dose-response)**

本项目对应课程的 **Problem → Data → Model → Benchmark → Biological interpretation** 五个环节。使用公开 Cell Painting / 图像表征数据，研究形态响应何时出现，以及能否用目标方向和额外形态变化筛选候选浓度。

**主要结论：双指标筛选是一种有代价的形态约束，没有证据表明它整体优于简单基线。所得浓度是形态候选，不是确认的有效剂量；额外偏离没有被验证为毒性。**

## 1. Problem：要回答什么

- 同一药物随浓度升高，形态从哪段浓度开始持续偏离对照？
- 对有健康与炎症参照的体系，药物是否沿目标方向移动，同时伴随其他变化？
- 相比只看目标方向的基线，额外偏离限制带来多少筛选收益与损失？选定浓度能否在留出板组重现？

研究的是体外培养液浓度（µM），不是人体给药量。轨迹连接不同孔、相同暴露时点的细胞群状态，未追踪同一个细胞，也未恢复完整细胞状态空间。

## 2. Data：数据与证据来源

**OASIS**：原代人肝细胞，44 小时暴露，8 档浓度。使用公开 CellProfiler 逐孔特征，复算环孢素 A、伊马替尼、胺碘酮三个案例。原研究还测量了代谢和膜损伤终点；本项目没有完成这些终点与形态的联合毒性归因，不能说原数据没有损伤实验。

- Ewald et al., *Cell Painting for cytotoxicity and mode-of-action analysis in primary human hepatocytes*, Cell Systems, 2026. [DOI](https://doi.org/10.1016/j.cels.2026.101566)
- [Zenodo 17067683](https://zenodo.org/records/17067683)：`metadata.parquet`、`cellprofiler_raw.parquet`。

**RxRx19b**：人脐静脉内皮细胞（HUVEC），先给药 1 小时再加入细胞因子刺激；包含实验健康参照、重度炎症参照和药物处理条件。70,384 个视野、53 块板、1,856 个化合物名称、10,758 个药物–浓度组合。每个视野有官方模型提供的 128 维表征；本项目不训练该图像网络。数据不是病毒感染实验，也不是先损伤后给药的治疗逆转。

- [官方数据说明](https://www.rxrx.ai/rxrx19b)、[元数据说明](https://github.com/recursionpharma/rxrx-datasets/blob/trunk/rxrx19b/README.md)。
- Cuccarese et al., *Functional immune mapping with deep-learning enabled phenomics applied to immunomodulatory and COVID-19 drug discovery*, 2020-08-14 版本预印本。[DOI](https://doi.org/10.1101/2020.08.02.233064)
- 所有数值分析基于公开特征；原论文 ECIS 屏障电阻图是文献证据，不是本组实验，也不与公开形态数据逐孔配对。

原始数据不放入 Git；下载后校验固定版本的摘要。两套数据不能拼成安全治疗窗口。

## 3. Model：实际拟合了什么

### OASIS：稳健形态偏离与持续响应

每块相关板的 69 个溶剂对照按固定随机种子划分为 29 个拟合、20 个校准、20 个留出孔。以拟合对照的中位数与 `1.4826 × MAD` 标准化特征；分别汇总线粒体、核区、内质网纹理的绝对偏差中位数，再以拟合对照的组分数中位数归一化，三组取最大值作为孔分数。同浓度重复孔取均值；校准对照匹配重复数建立均值的第 95 百分位界线。连续两档超过界线，报告前一档与第一档持续越界观测之间的采样定位区间。

该区间不是生物学阈值的置信区间。最低档已持续越界只能给出判据下的上界；未检出不能推出药物无效或安全。删点分析只检查采样敏感性，没有预测被删除浓度。

### RxRx19b：对照拟合的线性投影模型

每板每类对照固定分为 26 个拟合、13 个校准、13 个测试孔，三者不重叠。仅拟合对照用于计算健康中心 `h`、炎症中心 `s` 和各维组内标准差 `σ`。对药物表征 `x`：

```text
z = (x - h) / σ
d = (s - h) / σ
R = 1 - (z · d) / (d · d)
O = ||z - (1-R)d|| / q95
```

`q95` 来自每板校准对照（两类各 13 孔）的垂直距离第 95 百分位。`R` 是线性投影分数：炎症中心为 0、健康中心为 1；`O` 是目标轴以外的偏离比值。

这不是只有措辞的“模型”：中心、尺度、方向、偏离界线均由对照拟合，参数及每个划分的孔编号保存在 `results/benchmark/fitted_model.json`。它是利用已有图像表征的可解释统计模型，不是自行训练的深度网络。

**基线 M0**：同浓度 `median(R) >= 0.5`。

**双指标 M1**：同浓度 `median(R) >= 0.5` 且 `median(O) <= 1`。

两模型共用表征、拟合参数、浓度网格和划分，唯一差别是是否增加 O 限制。50% 是两参照中心的中间位置，不是 EC50；O 不是毒性分数。分别取两个中位数不保证每个孔同时合格，R>1 也不表示“比健康更健康”。规则在本次比较运行前固定，但此前已探索过这些数据；这不是预注册、盲测或外部验证。

## 4. Benchmark：实际结果与比较边界

### A. 留出对照：减少误选，同时损失健康参照

每种状态各 689 个留出孔。M0 把 14/689 个炎症对照判为通过，并保留 686/689 个健康对照；M1 把炎症误选降为 10/689，但健康保留也降为 633/689。

**加入 O 限制少误选了 4 个炎症孔，却额外排除了 53 个健康孔。不能据此宣布模型整体更好。** 这些是实验参照标签的结果，不是药物疗效准确率，也不是毒性灵敏度。R 在这批留出参照上的 AUC 为 0.995；AUC 是排序分离能力，不能替代给定阈值的代价分析。

### B. 药物筛选：同划分、固定浓度、统一留出指标

纳入各浓度具备一致六板布局的 1,816 种药物，另 40 种不符合此项设计。每个药物用 `SHA256(seed + 药物名)` 固定选择一个 3+3 板划分。发现三板选最低符合本方法规则的实测浓度，然后锁定浓度，在另外三板计算 R、O。两方法的发现/留出板完全相同。

- M0 发现组选出 138 种；留出组 80/138（58.0%）仍满足 R，8/138（5.8%）同时满足 R+O。
- M1 发现组选出 38 种；留出组 9/38（23.7%）仍满足 R，5/38（13.2%）同时满足 R+O。

共同评价终点为留出组的 R 达标与 R+O 双达标，不能用 M0 自身的 80 与 M1 自身的 5 冒充同一终点。两者选出的候选集合和浓度可能不同；这是两种筛选策略的产出/重现权衡，并非同预算随机试验。M1 的双达标比例较高，但绝对重现数量更少、R 单项重现比例更低；**这些结果不足以证明总体优越性，不能称为疗效 precision 或 recall**。

全量汇总时 M0 为 118 种/286 个浓度点，M1 为 15 种/22 点。这与发现部分的 138、38 不是同一次筛选，不能画成逐级漏斗。完整 20 个 3+3 组合另外保存为敏感性分析；组合之间相互依赖，不是 20 次独立实验。

### C. 多重比较与不确定性

在固定留出浓度上，以药物孔相对同板 13 个测试炎症对照的秩次提升检验 R；在每种策略的 1,816 种药物范围内分别作 BH 调整，未被发现组选中者赋 p=1。M0 有 70 个 R 提升结果通过调整后 p≤0.05，M1 为 0（最小调整后 p≈0.0945）。这检验的是 R 相对炎症对照的移动，不检验 R≥0.5、O≤1、功能疗效或安全性。策略不同导致被检验的浓度、p 值集合不同；相同药物原始 p 相同也可能有不同的调整后 p。

秩检验依赖零假设下同板孔可交换等条件；共享对照、同一实验内相关性和仅三个留出孔限制统计解释。因此按探索性分析报告，不把上述数量称为已经验证的有效药物。额外偏离没有匹配损伤标签，不能计算有生物学意义的毒性准确率。

## 5. Biological interpretation：可以说什么

- 环孢素 A 与胺碘酮的持续响应定位为 11–33.5 µM；伊马替尼为 3.5–11 µM。药物轨迹存在差异，不能据此归因于特异药理或一般毒性。
- 芦可替尼 0.25 µM 的全量中位数 R≈58.2%、O≈0.736，是最低实测双指标形态候选；六孔仅三孔同时达标。固定留出三板的中位数 R≈60.3%、O≈0.814，仍通过工作规则；这不是独立批次的疗效确认。
- 同药 1 µM 的 O≈1.01 接近工作界线，不应断言该浓度有毒；0.25 µM 的 O<1 也不证明安全。
- 卡博替尼某些条件形态偏离超界，而原论文另一项 ECIS 实验显示某些浓度屏障电阻改善。两者非逐孔配对；功能改善与毒性可并存，不能用这个案例证明“无毒”。

本项目完成了形态轨迹、可复算评分模型、基线比较和内部稳定性评测；**未完成高浓度机制归因、药效确认、毒性阈值或安全窗口估计**。

## 6. 运行与复现

测试环境为 Windows、Python 3.13.5，依赖见 `requirements.txt`。脚本接受显式数据路径，可以从任意工作目录运行。

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v

# 下载数值特征，不下载约 409 GB 的原始显微图像
python download_data.py rxrx19b
python download_data.py oasis

python benchmark.py
python oasis.py
python plot_results.py
python plot_presentation_results.py
python verify_results.py
```

如果已有数据：

```bash
python benchmark.py --data-dir /path/to/rxrx19b
python oasis.py --data-dir /path/to/oasis
```

`benchmark.py` 从元数据和 128 维原始表征重新拟合、评分、比较，不依赖以前生成的分数 CSV。`oasis.py` 从原始 CellProfiler 数据复算三个案例。下载脚本会检查固定版本校验值，已有但校验不一致的文件不会被覆盖。大表 `well_scores.csv`、`all_splits.csv` 不提交 Git，可运行生成；小型汇总、参数和固定划分结果随代码提交。
